Overview

hopbox.admin.v1.AdminKeyService

Section titled “hopbox.admin.v1.AdminKeyService”

AdminKeyService manages the admin API keys. An admin API key has install scope and calls the admin API, for example from the hopbox Terraform provider. It expires like other API keys. Only root on a control server, through the admin socket, calls this service, so no key makes another key.
