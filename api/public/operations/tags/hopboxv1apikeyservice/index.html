Overview

hopbox.v1.APIKeyService

Section titled “hopbox.v1.APIKeyService”

APIKeyService manages the API keys of an org. An API key belongs to one org and expires. A member key acts as its account in that org. An org key is a service credential of the org, with the rights of a member without personal resources. No API key can call this service, so no key makes, lists, or deletes another key.
