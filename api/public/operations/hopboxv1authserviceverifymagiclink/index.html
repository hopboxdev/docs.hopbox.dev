VerifyMagicLink

POST
/hopbox.v1.AuthService/VerifyMagicLink

VerifyMagicLink signs in with the token of a magic link, and sets the session cookie. The token of a link from RequestMagicLink with link adds the email to the account of the session that asked for it, and sets no cookie. Only that session can use it.
