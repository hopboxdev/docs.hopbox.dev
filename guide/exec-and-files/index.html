Run commands and copy files in a machine

This guide runs a command in a machine through the API, copies a file in and out, and reads the log of the start command. It uses the access calls of the API: Exec, Upload, Download, and StreamMachineLogs (the machine API). Use these calls from your own tools. The hopbox CLI does the same work with exec, cp, logs, and connect (Use machines from the CLI). The console uses the WebSocket of exec, and this guide shows it too.

Each access call needs a machine that runs, except the log. For a machine that does not run, the calls answer failed_precondition, with a message such as the machine box1 is pending, not running. Start it first.

What you need

Section titled “What you need”
  • A machine box1 that runs, as in Use machines from the CLI. This guide uses the install example.com.
  • An API key of your org in KEY, in the form hbx_<key>. Make one with KEY=$(hopbox api-key create tools --expires 30d), as in Use the hopbox CLI. An exec streams in both directions, so it needs gRPC or HTTP/2. A tool such as grpcurl speaks gRPC, so it sends the key.
  • grpcurl, from https://github.com/fullstorydev/grpcurl. The API serves gRPC reflection, so grpcurl needs no proto files.

The edge servers of the install serve the API over TLS on port 443:

Run a command

Section titled “Run a command”

Exec takes the start chunk first, then the input. In JSON, a bytes field such as stdin or stdout is base64. This command prints a line on each output, and exits with the code 3:

b3V0Cg== is out and a newline. Add "timeout":"10s" to the start chunk to end a command after 10 seconds. Such a command ends with the code 124 and "timedOut":true.

A member of the org cannot run a command in your machine until you share it. An org admin can never run one in your private machine (the machine API).

The mode 384 is 0600. A relative path starts at the home directory of the user user. To copy a directory, send a tar stream of its contents, with "archive":true.

Copy the file back

Section titled “Copy the file back”

A download to a laptop has at most 4 MiB. A larger file fails with failed_precondition. Pack the file in the machine and copy it in parts, or copy it over SSH.

Read the log

Section titled “Read the log”

Open a shell from the console

Section titled “Open a shell from the console”

The console opens a WebSocket to /api/ws/exec with the session cookie. Each binary message holds one ExecChunk encoded as protobuf. The generated messages of the TypeScript SDK, in @hopbox/sdk/v1, make and read it (Call the API from TypeScript). A start chunk without argv and with tty opens the login shell, as hopbox connect does:

The TypeScript SDK wraps this socket in exec, with the same session for a browser and for Node.js (Call the API from TypeScript). The page must have the origin of the install, so this works only from the console. A page of another site gets HTTP status 403. At the end of the shell, the socket closes with the code 1000. An error closes it with 4000 plus the Connect code, such as 4007 for permission_denied (the machine API).
